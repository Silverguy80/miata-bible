# Modified Miata Gang × Modified Miata Bible brand system

Two surfaces, one family.

## Shared DNA (keep these aligned)

| Token | Value | Use |
| --- | --- | --- |
| Black | `#000000` | Primary ink / shop canvas text / app shell |
| White | `#FFFFFF` | Shop ground / app type / hard offset shadows |
| Red | `#E10600` | Thin accent rule, primary CTA, danger, active marks |
| Gray | `#8A8A8A` | Secondary labels |
| Display type | Condensed heavy sans (Barlow Condensed) | Titles, merch-style stack headlines |
| Labels | IBM Plex Mono uppercase | Eyebrows, stamps, nav |
| Corners | `0` | Hard workshop/streetwear edges |
| Accent motif | Thin red rule under brand/title | Same as “Mod It. Race It. Rep It.” merch line |

## Distinguish the two

| | **Modified Miata Gang (shop)** | **Modified Miata Bible (app)** |
| --- | --- | --- |
| Job | Merch + community commerce | Workshop companion / manual / garage |
| Ground | White, airy product grid | Near-black graphite shell |
| Reading surface | Product cards on white | Off-white paper sheets on black |
| Brand mark | Full “Modified Miata Gang” wordmark | Compact `MB` mark + Bible name |
| Density | Sparse, photo-led | Dense tool UI, stamps, procedures |
| Footer / chrome | Shop checkout chrome | Local save / sync / export chrome |

Rule of thumb: if you strip the logo, the **shop** should still feel like a storefront; the **app** should still feel like a pit binder. Same palette and type, different surface language.

## Do not

- Recolor the shop into the old pit-blue / pit-yellow theme.
- Turn the Bible into a white ecommerce clone of the shop.
- Use multiple competing accent colors; red is the only loud accent.
- Soften into rounded “SaaS” cards; keep the hard MMG edges.

## Cross-links

- App chrome may link to the shop as a family surface.
- Shop merch / site may later deep-link into the Bible for fitment and service (same brand, different job).
